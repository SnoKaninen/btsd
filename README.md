# BTSD legal website

Privacy policy, terms and app support for BTSD — Bill · Track · Spend · Deduct.

- Privacy: https://snokaninen.github.io/btsd/
- Support: https://snokaninen.github.io/btsd/support/
- Terms: https://snokaninen.github.io/btsd/terms.html

This repository contains only public website files. App source and financial records are not included.
The design uses Alfa Omega as a read-only visual reference.

The source legal text is maintained in the BTSD project’s `legal/` folder.
Run `python3 tools/build_legal_site.py` there, then copy the generated `site/` contents here.
GitHub Pages serves the `main` branch from the repository root.
